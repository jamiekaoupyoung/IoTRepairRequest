# 商用洗衣 IoT 報修平台

以 `index.html` 為入口的單頁報修管理工具，無需安裝套件或啟動建置流程。

## 使用方式

直接以瀏覽器開啟 `index.html` 即可使用。也可以在專案目錄啟動任意靜態檔案伺服器，再以瀏覽器開啟其網址。

## 功能

- 報修列表：搜尋、依狀態篩選、分類與排序，並檢視案件處理資訊。
- 交易對照：依報修資料中的交易欄位檢核付款資訊。
- 分析儀表板：彙整報修案件與處理狀況。
- 新增及編輯報修單、處理備註與故障類型設定。
- 支援深色模式與窄螢幕版面。

## 資料與限制

`index.html` 內嵌的是匯出的報修資料快照，不是即時 API。新增、編輯、備註與類型設定儲存在目前瀏覽器的 `localStorage`，不會同步到原始系統；清除瀏覽器資料或改用其他瀏覽器時，這些本機修改不會保留。

「清除本機修改」會重設本機新增、編輯和類型設定，並恢復頁面內嵌的資料快照。
